Critical Analysis

Add tab content here.

Customisable Background

In the current application, the avatar view is limited to a plain black background, with no assets other than the avatar itself. Future versions of the application could allow the user to add custom backgrounds to add colour or match the context of the questionnaire. For example, a questionnaire meant for students could use a classroom backdrop.

Voice Synthesis

Our application allows for 3D models scanned using Avaturn.me to be used as avatars but currently only pre-set Kokoro TTS voices can be used. If support were added for a TTS with voice cloning functionality, it would be possible to create avatars that not only look but also sound like the intended person. This could be useful in applications such as SEND schools, where a student may be more comfortable answering questions if the interviewer has the appearance of a family member or teacher.

Different Model Sources e.g. Foundry Local

Currently we are using a Llamafile for local LLM inferencing. This works effectively but the LLamafile has to be included in the packaged application, which adds ~3 GB to the file size. Integration with Foundry Local would mean that our application could be distributed in a more lightweight way and integrate more tightly with the Windows ecosystem.

Sign Language Support

A key success of our application was the support for multilingual input to help facilitate communication across language barriers. However, AvatarForms currently only supports voice and text input. If paired with a camera and an existing sign language recognition library, our avatar would be able to interpret sign language to interview individuals with speech issues.
